## 📌 Présentation

Carte de **statistiques** en deux colonnes : texte (titre avec mot en violet, paragraphe, 3 chiffres clés) et image avec **filtre de couleur violet** obtenu par superposition / `mix-blend-mode`. Sur mobile, l'image passe au-dessus du texte.

Ce projet fait partie de ma **première série de défis Frontend Mentor (juin–juillet 2024)**,
réalisée en **HTML et CSS purs**, sans outil de build ni framework, pour consolider les
fondamentaux avant de passer à Sass, Tailwind puis Vue.

## ✨ Fonctionnalités

- Image teintée en violet (overlay + `mix-blend-mode: multiply`).
- Ordre des colonnes inversé entre mobile et desktop.
- Chiffres clés (10k+, 314, 12M+) avec libellés en capitales espacées.
- Polices Inter et Lexend Deca.
